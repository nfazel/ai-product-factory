# Discovery

Explore is the first stage for every product. Create Product asks what you are starting with.

## I have an idea

The product is stored with start mode `IDEA`. This is also the default for products created before start mode existed.

Explore opens Product Discovery. The conversation and the Product Brief work as before. A person approves the brief. Move to Define stays a separate action, and it still requires that approval. The product stage does not change when the brief is approved.

## I already have requirements

The product is stored with start mode `EXISTING_REQUIREMENTS` and still begins in Explore.

Explore opens Requirements Intake instead of the blank-sheet conversation. The person pastes text or uploads a supported document. Analysis proposes a Product Brief labelled as drafted from the requirements. A person edits and approves that same Product Brief. Move to Define uses the same gate as idea mode.

After that, Define is the same product definition: outcomes, capabilities, the first slice, work items, acceptance criteria, and non-functional requirements. There is no imported definition and no extra lifecycle stage.

The intake rules, file limits, and traceability are described in [existing-requirements.md](existing-requirements.md).
